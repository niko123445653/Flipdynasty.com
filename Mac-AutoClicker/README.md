# NOVA CLICKER for macOS

A small macOS autoclicker with a Start/Stop button and adjustable speed (1–100 clicks per second).

## Build it on a Mac

1. Download this folder from the repository.
2. Open Terminal and go into this folder.
3. Run: `chmod +x build.command`
4. Run: `./build.command`
5. Open the `NOVA CLICKER.app` created in this folder.

## First launch permission

macOS requires Accessibility permission so the app can send clicks:
- Open **System Settings → Privacy & Security → Accessibility**.
- Enable **NOVA CLICKER**.
- Return to the app and press Start.

## How to use

1. Move your mouse pointer to the place you want clicked.
2. Choose a speed from 1 to 100 CPS.
3. Press **START AFK CLICKING**.
4. Press **STOP CLICKING** to stop.

The app clicks the current pointer location with the left mouse button. Keep the app open while it runs. Use it only where automated clicking is allowed.
